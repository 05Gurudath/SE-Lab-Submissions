# Lab 2 - Agile Backlog Creation & Sprint Simulation in Jira

## Objective
To use Jira to convert functional requirements into Agile backlog items, organize and prioritize user stories, estimate story points, simulate a sprint, and analyse project progress.

## Project
**Telemedicine Slot Booking & Prescription Portal**

## Description
This lab focuses on using Jira for Agile project management. The functional requirements identified in Lab 1 were converted into Epics and User Stories. The backlog was organized, priorities were assigned, and story points were estimated based on complexity.

A sprint was simulated by moving tasks through different stages and monitoring progress using the Burndown Chart.

## Work Completed

1. Created and organized Epics in Jira.
2. Created User Stories under the respective Epics.
3. Prioritized backlog items based on importance and user requirements.
4. Assigned story points using effort estimation.
5. Created and simulated a sprint in Jira.
6. Tracked task progress through the sprint workflow.
7. Generated and analysed the Burndown Chart.
8. Answered the sprint reflection questions.

## Story Point Estimation
User Stories were assigned 3 or 5 story points based on their complexity and estimated effort.

## Sprint Results
The completed sprint report showed:

- Total completed story points: 16
- Completed User Stories: 4
- All four displayed stories were marked as DONE.

### Completed User Stories

| Issue | User Story | Story Points |
|---|---|---:|
| CK-10 | Author and Digitally Sign Prescriptions | 5 |

## Reflection
The sprint estimations reasonably reflected the actual effort. The backlog was prioritized according to the importance of the telemedicine system. The selected sprint work was completed, and the Burndown Chart indicated that the team completed 16 story points.
