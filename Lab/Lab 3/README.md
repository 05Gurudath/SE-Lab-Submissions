# Lab 3 - Component Modelling & Architectural Pattern Selection

## Problem Statement
Telemedicine Slot Booking & Prescription Portal

## Objective
To evaluate architectural styles, select a suitable architecture, and create a UML Component Diagram showing the system modules, interfaces, and dependencies.

## Architecture Selected
Layered Architecture

## Work Completed
1. Created a UML Component Diagram.
2. Identified system components and their interactions.
3. Identified Patient and Attending Physician as actors.
4. Selected Layered Architecture.
5. Prepared written justification for the architecture selection.

## Main Components
- Patient Portal
- Physician Portal
- Authentication Service
- Slot Booking Service
- Teleconsultation Service
- Prescription Service
- Healthcare Database
