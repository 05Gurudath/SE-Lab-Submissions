# Lab 6 – Code and Branch Coverage Analysis

## Objective

To understand code coverage and branch coverage, write test cases, and analyse the effectiveness of software testing using Python coverage tools.

## Project

**Bus Transit Fare System**

## Description

This lab focuses on analysing the test coverage of the Bus Transit Fare System. The application was tested using pytest and the coverage tool to identify executed lines and untested branches.

## Work Completed

1. Analysed the existing bus transit fare application.
2. Created test cases for code coverage.
3. Executed tests using pytest.
4. Generated code coverage reports.
5. Created additional test cases for branch coverage.
6. Analysed different execution paths and conditions.
7. Improved test coverage by adding test cases.

## Tools Used

- Python
- pytest
- coverage
- VS Code
- GitHub

## Files Included

- `bus_transit_fare.py` – Main application.
- `CodeCoverageTest_bus_transit_fare.py` – Code coverage test cases.
- `BranchCoverageTest_bus_transit_fare.py` – Branch coverage test cases.
- `test_bus_transit.py` – Additional test cases.
