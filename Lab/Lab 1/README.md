# Lab 1 - Requirements Engineering & UML Use-Case Modelling

## Problem Statement
**Telemedicine Slot Booking & Prescription Portal**

## Objective
To identify functional and non-functional requirements for a telemedicine system and represent the system functionality using a UML Use-Case Diagram.

## Description
This lab focuses on analysing the requirements of a healthcare consultation portal that allows patients to view doctor specialities, book video consultations, receive consultation room links, and access digital prescriptions.

Attending physicians can author and digitally sign prescriptions for patients.

## Work Completed
1. Identified functional requirements (FR-001 to FR-005).
2. Identified non-functional requirements (NFR-001 and NFR-002).
3. Prepared the requirements table with descriptions, priorities, acceptance criteria, and rationale.
4. Created a UML Use-Case Diagram.
5. Identified system actors and their interactions.

## Actors
- Patient
- Attending Physician
